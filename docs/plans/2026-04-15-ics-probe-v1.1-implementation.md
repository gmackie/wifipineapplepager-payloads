# ICS Probe v1.1 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Expand the approved ICS/OT probe (v1) firmware, hardware, and payload library with three new capabilities — Ethernet uplink (W5500), 24V industrial digital I/O (MAX14906), and 4–20mA current output (AD5420) — so the probe can run consulting POCs in plant environments.

**Architecture:** The v1 probe is an ESP32-S3 exposing a JSON-over-USB-CDC command protocol with a per-protocol handler pattern (`init()` / `is_ready()` / `handle_command()`) dispatched from `main.c`. v1.1 adds three new handlers following the same pattern plus a new isolated 24V field domain on a shared SPI bus. The pager-side shell library (`library/user/ics/lib/esp32.sh`) gains wrapper functions for each new command module, and nine new payloads exercise the new capabilities.

**Tech Stack:** ESP-IDF v5.1.2 (C), cJSON, FreeRTOS, esp_eth (W5500 built-in driver), ESP-IDF SPI master driver, Bash (payload layer), POSIX shell utilities on OpenWrt pager.

**Reference design doc:** [docs/plans/2026-03-23-ics-ot-probe-design.md](./2026-03-23-ics-ot-probe-design.md) — read Amendments 8–14 for the full v1.1 scope before starting any task.

### Task 2.2: Implement net_init with W5500 + esp_netif + lwIP

**File:**
- Modify: `firmware/ics-probe/main/net_handler.c`

**Step 1:** Replace the stub `net_init` with full W5500 + esp_netif init:

```c
#include "esp_eth.h"
#include "esp_eth_mac_spi.h"
#include "esp_netif.h"
#include "esp_event.h"
#include "driver/spi_master.h"
#include "lwip/sockets.h"
#include "lwip/netdb.h"
#include "lwip/dhcp.h"

static esp_netif_t* s_eth_netif = NULL;
static esp_eth_handle_t s_eth_handle = NULL;

void net_init(void)
{
    ESP_LOGI(TAG, "initializing W5500 Ethernet");

    // SPI3 already used by MCP2515 — reuse the bus, add a new device handle.
    // Bus config is a no-op if already initialized.
    spi_bus_config_t bus_cfg = {
        .mosi_io_num = CAN_SPI_MOSI,
        .miso_io_num = CAN_SPI_MISO,
        .sclk_io_num = CAN_SPI_CLK,
        .quadwp_io_num = -1,
        .quadhd_io_num = -1,
    };
    esp_err_t err = spi_bus_initialize(SPI3_HOST, &bus_cfg, SPI_DMA_CH_AUTO);
    if (err != ESP_OK && err != ESP_ERR_INVALID_STATE) {
        // INVALID_STATE = already initialized by can_handler, which is fine
        ESP_LOGW(TAG, "SPI bus init failed: %s", esp_err_to_name(err));
        s_initialized = false;
        return;
    }

    eth_w5500_config_t w5500_cfg = ETH_W5500_DEFAULT_CONFIG(SPI3_HOST, NULL);
    w5500_cfg.int_gpio_num = W5500_INT_PIN;
    spi_device_interface_config_t devcfg = {
        .mode = 0,
        .clock_speed_hz = W5500_SPI_MHZ * 1000 * 1000,
        .spics_io_num = W5500_CS_PIN,
        .queue_size = 20,
    };
    w5500_cfg.spi_devcfg = &devcfg;

    eth_mac_config_t mac_cfg = ETH_MAC_DEFAULT_CONFIG();
    eth_phy_config_t phy_cfg = ETH_PHY_DEFAULT_CONFIG();
    phy_cfg.phy_addr = W5500_PHY_ADDR;
    phy_cfg.reset_gpio_num = W5500_RST_PIN;

    esp_eth_mac_t* mac = esp_eth_mac_new_w5500(&w5500_cfg, &mac_cfg);
    esp_eth_phy_t* phy = esp_eth_phy_new_w5500(&phy_cfg);
    if (!mac || !phy) {
        ESP_LOGW(TAG, "W5500 not detected");
        s_initialized = false;
        return;
    }

    esp_eth_config_t eth_cfg = ETH_DEFAULT_CONFIG(mac, phy);
    if (esp_eth_driver_install(&eth_cfg, &s_eth_handle) != ESP_OK) {
        ESP_LOGW(TAG, "esp_eth_driver_install failed");
        s_initialized = false;
        return;
    }

    // Assign MAC address (W5500 has no built-in)
    uint8_t mac_addr[6] = { 0x02, 0x00, 0x00, 0x12, 0x34, 0x56 };
    ESP_ERROR_CHECK(esp_eth_ioctl(s_eth_handle, ETH_CMD_S_MAC_ADDR, mac_addr));

    // Initialize TCP/IP stack
    esp_netif_init();
    esp_event_loop_create_default();
    esp_netif_config_t netif_cfg = ESP_NETIF_DEFAULT_ETH();
    s_eth_netif = esp_netif_new(&netif_cfg);
    esp_netif_attach(s_eth_netif, esp_eth_new_netif_glue(s_eth_handle));

    esp_eth_start(s_eth_handle);

    s_initialized = true;
    ESP_LOGI(TAG, "W5500 Ethernet ready");
}
```

### Task 2.3: Implement net.status and net.dhcp commands

**File:**
- Modify: `firmware/ics-probe/main/net_handler.c`

**Step 1:** Replace `net_handle_command` with a dispatch that handles `status`, `dhcp`, `static`, and `selftest`:

```c
static cJSON* cmd_status(void)
{
    cJSON* resp = cJSON_CreateObject();
    cJSON_AddStringToObject(resp, "status", "ok");
    if (!s_initialized) {
        cJSON_AddBoolToObject(resp, "link", false);
        cJSON_AddStringToObject(resp, "error", "not_initialized");
        return resp;
    }
    esp_netif_ip_info_t ip;
    if (esp_netif_get_ip_info(s_eth_netif, &ip) == ESP_OK) {
        char buf[32];
        snprintf(buf, sizeof(buf), IPSTR, IP2STR(&ip.ip));
        cJSON_AddStringToObject(resp, "ip", buf);
        snprintf(buf, sizeof(buf), IPSTR, IP2STR(&ip.netmask));
        cJSON_AddStringToObject(resp, "netmask", buf);
        snprintf(buf, sizeof(buf), IPSTR, IP2STR(&ip.gw));
        cJSON_AddStringToObject(resp, "gw", buf);
    }
    bool link_up = false;
    esp_eth_ioctl(s_eth_handle, ETH_CMD_G_PHY_LINK, &link_up);
    cJSON_AddBoolToObject(resp, "link", link_up);
    return resp;
}

static cJSON* cmd_dhcp(cJSON* params)
{
    cJSON* resp = cJSON_CreateObject();
    if (!s_initialized) {
        cJSON_AddStringToObject(resp, "status", "error");
        cJSON_AddStringToObject(resp, "error", "not_initialized");
        return resp;
    }
    int timeout_s = 10;
    cJSON* t = cJSON_GetObjectItemCaseSensitive(params, "timeout_s");
    if (t && cJSON_IsNumber(t)) timeout_s = t->valueint;

    esp_netif_dhcpc_stop(s_eth_netif);
    esp_netif_dhcpc_start(s_eth_netif);

    // Poll for IP assignment
    for (int i = 0; i < timeout_s * 10; i++) {
        esp_netif_ip_info_t ip;
        if (esp_netif_get_ip_info(s_eth_netif, &ip) == ESP_OK && ip.ip.addr != 0) {
            cJSON_AddStringToObject(resp, "status", "ok");
            char buf[32];
            snprintf(buf, sizeof(buf), IPSTR, IP2STR(&ip.ip));
            cJSON_AddStringToObject(resp, "ip", buf);
            return resp;
        }
        vTaskDelay(pdMS_TO_TICKS(100));
    }
    cJSON_AddStringToObject(resp, "status", "error");
    cJSON_AddStringToObject(resp, "error", "dhcp_timeout");
    return resp;
}

cJSON* net_handle_command(const char* action, cJSON* params)
{
    if (!action) {
        cJSON* r = cJSON_CreateObject();
        cJSON_AddStringToObject(r, "status", "error");
        cJSON_AddStringToObject(r, "error", "missing_action");
        return r;
    }
    if (strcmp(action, "selftest") == 0 || strcmp(action, "status") == 0) {
        return cmd_status();
    }
    if (strcmp(action, "dhcp") == 0)   return cmd_dhcp(params);
    // static, tcp_*, udp_send lands in Task 2.4+
    cJSON* r = cJSON_CreateObject();
    cJSON_AddStringToObject(r, "status", "error");
    cJSON_AddStringToObject(r, "error", "unknown_action");
    return r;
}
```

## Phase 3: Digital I/O Handler (MAX14906)

### Task 3.1: Create MAX14906 SPI register driver

**Files:**
- Create: `firmware/ics-probe/main/max14906.h`
- Create: `firmware/ics-probe/main/max14906.c`

**Reference:** MAX14906 datasheet. Key registers:
- `0x00 SetOUT` — per-channel output state
- `0x01 SetLED` — LED control
- `0x02 DoiLevel` — per-channel input voltage levels (read)
- `0x03 Interrupt` — fault flags
- `0x04 OvrLdChF` — overload/short-circuit flags
- `0x0A Config1` — per-channel mode select (high-side switch / push-pull / input)
- `0x0B Config2` — filter, debounce
- `0x0D DoiLvl` — digital input thresholds (Type 1/2/3)

SPI format: 16-bit frames. First byte = address + R/W bit. Second byte = data. Response = previous register value.

**Step 1:** Create `max14906.h`:

```c
#pragma once
#include <stdint.h>
#include <stdbool.h>
```

## Phase 4: Current Output Handler (AD5420)

### Task 4.1: Create AD5420 SPI register driver

**Files:**
- Create: `firmware/ics-probe/main/ad5420.h`
- Create: `firmware/ics-probe/main/ad5420.c`

**Reference:** AD5420 datasheet. Key points:
- 24-bit SPI writes (8-bit address + 16-bit data)
- Control register (0x55) selects output range (0x05 = 4–20mA)
- DAC data register (0x01) is 16-bit unsigned
- Mapping: 0x0000 = 4mA, 0xFFFF = 20mA, linear

**Step 1:** Create `ad5420.h`:

```c
#pragma once
#include <stdint.h>
#include <stdbool.h>

bool ad5420_init(void);
bool ad5420_set_ma(float ma);
bool ad5420_off(void);
uint16_t ad5420_read_status(void);
```

**Step 2:** Create `ad5420.c`. In `ad5420_set_ma`:
- Clamp to `[IOUT_MIN_MA, IOUT_MAX_MA]`
- Convert to 16-bit code: `code = (uint16_t)((ma - 4.0f) / 16.0f * 65535.0f)` for the 4–20mA range
- Write control register (one-time in init) then DAC data register

## Testing Strategy Summary

**Firmware:** ESP-IDF lacks a host-side unit test harness in this project, so primary verification is:
1. **Build gate** — `idf.py build` must pass after every task
2. **Static gate** — no new compiler warnings beyond existing baseline
3. **Bring-up integration test** — flash to hardware and exercise each handler via serial (Tasks 2.7, 3.8, 4.6, 7.4)
4. **Graceful degradation** — handlers must return `not_initialized` cleanly when their IC is missing; the firmware must never crash on startup without the new hardware wired in

**Pager-side shell library:** Unit-testable via shell mocks (Task 5.4). Run on a host that has `bash`.

**Payloads:** Syntax check via `bash -n` per task, shellcheck batch at Task 6.10, runtime validation requires the actual pager + probe.
