## JLCPCB Order Notes

1. **PCB specs:** 2-layer (or 4-layer if routing is tight around W5500), 1.6mm FR4, HASL lead-free, green solder mask.

2. **Assembly tier:** Must use **Standard PCBA** (not Economic) because of through-hole parts (connectors, RJ45). Standard supports mixed SMD+THT.

3. **MAX14906 footprint:** Include the TSSOP-24 footprint on the PCB with pads. Mark as "DNP" (Do Not Populate) in the JLCPCB BOM so they skip it. You'll hand-solder it.

4. **W5500 package:** The LCSC part (C32843) is **LQFP-48** (7x7mm, 0.5mm pitch), NOT QFN-48. Design the footprint for LQFP-48.

5. **Isolation domains:** The PCB must have clearly separated ground planes — logic-side GND and field-side GND with the ADUM isolators spanning the gap. This is a routing constraint, not a BOM issue, but it's critical for galvanic isolation to actually work.

6. **Connector placement:** Screw terminals and RJ45 on board edge. USB-A male extends beyond the board edge (or use a right-angle variant that sits flush).

7. **Crystal placement:** 25MHz crystal must be close to W5500 (within 10mm) with short traces and ground pour underneath.
